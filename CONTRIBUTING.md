# Contributing

Foliora is currently an in-development scaffold. Contributions should preserve
its license boundaries and avoid claiming unsupported functionality.

## Before submitting

- Read `README.md` and the relevant documentation.
- Keep fixtures synthetic and clearly labeled.
- Do not add secrets or personal data.
- Run `cargo check --workspace` and the relevant package checks.
- Explain behavior changes and tests in the pull request.

Application code is AGPL-3.0-or-later. Independent schema and protocol
definitions are Apache-2.0; keep their notices intact.

The Foliora name is provisional and not cleared for use as a trademark.
