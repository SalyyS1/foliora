# Provisional brand assets

Foliora is a provisional codename and has no trademark clearance.

`foliora-symbol.svg` is the original vector source for the provisional app icon.
It represents two offset document leaves joined by an open path: context is
connected, while the open end keeps sharing under the user's control. It avoids
certification shields, checkmarks, infinity loops and AI imagery.

Generated platform icons live in `apps/desktop/src-tauri/icons/` and must be
regenerated from this SVG rather than edited independently. The symbol and name
remain provisional until naming and trademark review is complete.
